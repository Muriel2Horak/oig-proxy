# OIG Proxy Twin

Aktuální vstupní témata MQTT, formát příkazů, potvrzování výsledků a chování
po restartu popisuje [ovládání přes MQTT](v2/twin.md). Popis toku a rozdělení
odpovědností je v [architektuře proxy](v2/architecture.md).

Pro práci v Home Assistantu použijte [návod k lokálnímu ovládání](v2/local-control.md).
Volby aplikace, které ovládání povolují a určují povolené hodnoty, uvádí
[referenční přehled konfigurace](v2/configuration.md).
